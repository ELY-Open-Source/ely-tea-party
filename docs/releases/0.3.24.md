本版同步了上游 ELYTerminal 0.2.5：会话内可以分屏，所有快捷键都可以自己改。

## 新功能

- **分屏**：一个会话里可以分出多个终端。Cmd-D 向右分，Cmd-Shift-D 向下分，Cmd-] 和 Cmd-[ 在分屏之间切换；Windows 和 Linux 上是 Ctrl-Shift-E、Ctrl-Shift-Alt-O、Ctrl-Shift-N 和 Ctrl-Shift-P。
- **自定义快捷键**：设置 › 终端 › 快捷键 里可以搜索并修改每一条命令的按键，包括快速切换、抽屉和茶会。
- **清屏和全屏**：清屏是 Cmd-Shift-K（Windows 和 Linux 上 Ctrl-Shift-Alt-K）；全屏是 Ctrl-Cmd-F（Windows 和 Linux 上 F11）。
- **粘贴和关闭前询问**：粘贴多行内容前会先问一下；退出或关窗会结束正在运行的程序时也会先问。两项都可以在 设置 › 终端 关掉。
- **命令行**：`ely-tea-party -e 程序 [参数…]` 用第一个会话直接运行一个程序。在 设置 › 终端 打开“命令行控制”后，`ely-tea-party ctl` 可以列出会话、读取内容和输入文字。
- **选择和背景**：拖选到终端上下边缘时会自动滚动；背景图可以加渐变、单独的不透明度和遮罩。
- **Windows**：可以在 设置 › 终端 把 Ely Tea Party 设为默认终端；Ctrl-Insert 复制、Shift-Insert 粘贴；MSYS2 的 fish 能报告当前文件夹。

## 修复

- KDE Plasma 的 Wayland 上移动窗口时，Ely 不再抖动。
- 来自上游的其他终端修复。

## 兼容性

- 角色只跟着会话的第一个分屏：在分出来的终端里启动的 agent 不会显示成这个会话的角色，hooks 和会话间消息也不经过它。
- 重启后只恢复每个会话的第一个分屏。
- 只要有 agent 在运行，退出和关窗就会询问。不需要的话请在 设置 › 终端 关掉“关闭运行中的会话前确认”。
- 清屏没有用 Cmd-K，因为它是快速切换的按键。

## What's new

This release syncs with upstream ELYTerminal 0.2.5: a session splits into panes, and every shortcut can be changed.

- **Split panes.** A session holds several terminals. Cmd-D splits right, Cmd-Shift-D splits down, and Cmd-] and Cmd-[ step between panes; on Windows and Linux, Ctrl-Shift-E, Ctrl-Shift-Alt-O, Ctrl-Shift-N and Ctrl-Shift-P.
- **Your own shortcuts.** Settings › Terminal › Shortcuts searches and changes the keys of every command, the session switcher, the drawer and the tea party among them.
- **Clear and full screen.** Clear is Cmd-Shift-K, or Ctrl-Shift-Alt-K on Windows and Linux. Full screen is Ctrl-Cmd-F, or F11.
- **A question before a paste or a close.** A paste of several lines asks first, and so does a quit or a close that would end a running program. Settings › Terminal turns either off.
- **Command line.** `ely-tea-party -e PROGRAM [ARG…]` runs a program as the first session. With Command line control on in Settings › Terminal, `ely-tea-party ctl` lists sessions, reads them and types into them.
- **Selection and background.** A selection dragged past the terminal's top or bottom scrolls the history. A background picture takes a gradient, its own opacity and a mask.
- **Windows.** Settings › Terminal can make Ely Tea Party the default terminal. Ctrl-Insert copies and Shift-Insert pastes. MSYS2's fish reports its folder.

## Fixes

- On KDE Plasma's Wayland, Ely no longer twitches while the window moves.
- Upstream's other terminal fixes.

## Compatibility

- A session's character follows its first pane only: an agent started in a split is not shown as the session's, and hooks and session messages do not reach it.
- Only a session's first pane comes back after a restart.
- While any agent runs, quitting and closing the window ask first. Turn off Ask before closing running sessions in Settings › Terminal if you do not want that.
- Clear is not Cmd-K, which the session switcher holds.
