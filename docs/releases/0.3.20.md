本版让多会话任务更容易跟进：先处理需要你回应的任务，再查看完成结果，并由你确认是否处理完毕。

## 新功能

- **统一任务状态**：侧边栏、Tea Party 和鲸鱼任务卡使用同一套状态；错误、等待回复和待查看的完成结果优先提醒。侧边栏仍保留你的会话顺序。
- **查看完成结果**：从会话的书本按钮、已完成的 Tea Party 卡片或鲸鱼面板详情，查看最近一轮的收尾回复和命令事件，并直接打开该会话的 Git 改动或 Activity。
- **手动确认**：查看结果后仍会保留待处理提醒；点击“我已检查”才将其标为已处理，也可以重新打开检查。开启恢复会话后，查看和确认状态会随 Activity 保存。
- **更完整的回复**：新收到的完成事件保留最多 8 KiB 的收尾文本及换行；过长时会显示省略标记。

## 使用说明

- 结果卡展示主终端最近一轮任务；历史轮次和抽屉里的 agent 记录仍在 Activity。
- 命令事件来自 agent 的 hooks；工具返回并不等于测试全部通过。手动确认也不会执行测试或批准 agent 权限。
- Git 改动展示当前工作目录的全部变化；多人或多个 agent 共用目录时，其中可能包含其他任务的修改。
- 旧记录保留原来保存的短摘要；没有提供收尾文本的 agent 会显示暂无回复。

## What's new

This release makes multi-session work easier to follow: respond to tasks that need attention, inspect completed results, and explicitly mark them handled.

- **Consistent task states.** The sidebar, Tea Party and whale task cards agree on errors, waiting tasks and completions awaiting review. The sidebar keeps your session order.
- **Result review.** Use a session's book button, a completed Tea Party card or the whale panel's details to read the latest closing reply and command events, then open that session's Git changes or Activity.
- **Explicit acknowledgment.** Viewing a result leaves it awaiting review. Mark it handled after checking it, or reopen it for review. With Restore sessions enabled, review state is saved with Activity.
- **Longer closing replies.** New completion events preserve up to 8 KiB of text with line breaks and an ellipsis when clipped.

## Notes

- Result cards show the newest turn in each main terminal. Earlier turns and drawer agents remain in Activity.
- Command events come from agent hooks; a returned tool does not establish that every test passed. Acknowledgment runs no tests and grants no agent permissions.
- Git shows the current checkout's entire diff, which can include edits from other tasks sharing that directory.
- Older records keep their original short excerpts. Agents without closing text show an empty state.
