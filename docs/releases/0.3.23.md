本版让对话导航刻度随会话一起恢复。

## 新功能与修复

- **恢复会话时找回导航刻度**：重启或升级应用后，恢复的会话会从 agent 自己的对话记录里读回历史输入，终端左侧的刻度不再是空的。支持 Claude Code、Codex 和 Antigravity；其他 agent 使用应用保存的活动记录。
- **恢复后可跳转**：agent 重新显示对话内容时，刻度会按顺序重新定位，点击即可跳到对应输入。未能定位的输入仍显示刻度和预览。
- **回复预览**：Claude Code 和 Codex 的刻度预览会同时显示该轮的回复；Antigravity 的记录只包含输入，预览只显示输入。

## What's new

This release brings the prompt navigation ticks back with a restored session.

- **Ticks return with a restored session.** After a restart or an update, a restored session reads its earlier prompts from the agent's own record of the conversation, so the terminal's left gutter is no longer empty. Claude Code, Codex and Antigravity are supported; other agents use the activity the app keeps.
- **Jump after restoring.** As the agent shows the conversation again, the ticks are located in order, and a click jumps to the prompt. A prompt that is not located still shows its tick and preview.
- **Reply previews.** Ticks for Claude Code and Codex preview the reply that ended each turn; Antigravity's record holds prompts only, so its previews show the prompt alone.
