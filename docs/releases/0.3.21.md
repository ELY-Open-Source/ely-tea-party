本版让本机会话更容易查找和协作：按文件夹浏览，用快捷键切换，再通过 App 自带的 CLI 在会话之间收发消息。

## 新功能

- **紧凑侧边栏**：在设置 → 外观中选择紧凑模式，以文件夹分组展示会话，用小图标区分 coding agent。原有角色模式仍是默认选项。
- **快速切换会话**：macOS 按 `⌘K`，Windows 和 Linux 按 `Ctrl+Shift+K`，按标题、文件夹或 agent 搜索所有窗口中的本机会话；支持多个关键词和键盘选择。
- **本机会话通信**：内置 `ely-tea-party msg` CLI，支持会话发现、发信、收件箱、回复和确认已读。使用独立会话地址投递，并支持请求重试去重。
- **随 App 更新的 CLI 和 skill**：App 内终端自动获得 CLI 路径。在设置 → 终端 → Agent 通信集成中安装 Claude Code 或 Codex 的 skill；已托管的入口会随 App 启动检查并更新，用户修改过的文件会保留并提示。

## 修复与使用说明

- 修复多个窗口之间的 agent hook 分发，并在退出时清理通信 socket。
- 修复 Windows checkout 换行引起的 skill 校验差异，并验证了 Windows 的 CLI 安装、同步和修改保护测试。
- 接收方需要主动读取收件箱；消息不会自动唤醒 agent，也不会向终端注入文本。返回 `stored` 表示消息已保存，不代表对方已读。
- 安装 skill 后，如果运行中的 agent 尚未发现它，请重新启动 agent。完整指引通过 `ely-tea-party msg guide` 从当前 App 读取。
- 通信仅覆盖当前 App 的本机主终端会话；不包含跨机器管理、抽屉的独立通信身份或持久 agent 运行。App 重启后的旧消息不会分配给新会话。

## What's new

Find and coordinate local sessions more easily: browse by folder, switch with a shortcut, and exchange messages through the CLI bundled with Ely.

- **Compact sidebar.** Choose Compact in Settings → Appearance to group sessions by folder with small coding-agent icons. Characters remains the default.
- **Quick session switching.** Press `⌘K` on macOS or `Ctrl+Shift+K` on Windows/Linux to search local sessions across windows by title, folder or agent, with multiple search terms and keyboard navigation.
- **Local session messaging.** The bundled `ely-tea-party msg` CLI supports discovery, sending, inboxes, replies and explicit acknowledgment. Exact session addresses and retry keys prevent ambiguous routing and duplicate retries.
- **CLI and skill updates with the app.** Ely terminals receive the bundled CLI on PATH. Install Claude Code or Codex skill entries in Settings → Terminal → Agent messaging integration. Startup updates owned entries and preserves user modifications.

## Fixes and notes

- Agent hooks now reach sessions across windows, and messaging sockets are cleaned up on exit.
- Bundled skill resources retain consistent line endings on Windows; Windows CI covers CLI installation, syncing and protection of user edits.
- Recipients explicitly check their inbox. Messages do not wake agents or inject terminal input. A `stored` receipt confirms storage, not reading.
- Restart an agent if it has not discovered a newly installed skill. `ely-tea-party msg guide` reads the complete instructions from the running app.
- Messaging covers this app's local main-terminal sessions. Remote machines, separate drawer identities and persistent agent execution are outside this release. Old messages are not reassigned to new sessions after an app restart.
