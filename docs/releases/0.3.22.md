本版改进终端内容分享和对话导航。

## 新功能与修复

- **将抽屉终端内容发送给 agent**：打开底部终端后，可预览并分享输出给当前会话的 agent；发送前会对常见敏感信息进行脱敏。请在预览中确认分享内容。
- **紧凑的对话导航刻度**：终端左侧改为垂直居中、固定间距的短刻度，每次用户输入对应一条，不再随回复长度拉散。
- **悬停预览与跳转**：悬停时当前及邻近刻度伸长，并显示对应输入和回复预览；点击已定位的刻度跳转到该输入。
- **长对话导航**：刻度较多时可在左侧区域内滚动，当前对话位置会高亮；已离开回滚记录或尚未定位的输入会显示说明。

## What's new

This release improves terminal context sharing and conversation navigation.

- **Share drawer output with the agent.** Preview output from the bottom terminal and send it to the current session's agent, with common sensitive information redacted before sending. Review the preview before sharing.
- **Compact prompt navigation.** The terminal's left gutter now holds a vertically centered stack of fixed-spacing ticks, one per user prompt, independent of reply length.
- **Preview and jump.** Hover to expand nearby ticks and preview the prompt and reply; click a located tick to jump to the corresponding input.
- **Long conversations.** Scroll long tick lists within the gutter, follow the highlighted current turn, and see explanations for prompts that are no longer in scrollback or have not been located.
