本版同步了上游 ELYTerminal 0.2.0。

## 新功能

- **终端里显示图片**：支持 kitty 图形协议，包括动图，用这个协议的程序可以直接在终端里显示图片。切到别的会话时，图片占用的显存会释放。
- **kitty 剪贴板协议（OSC 5522）**：程序可以读写剪贴板里的文字、图片和文件列表。程序读取剪贴板前会先问你，可以选择本会话内一直允许。
- **自定义主题和背景图**：设置 › 外观里可以基于 Ely Dark 新建自己的主题，也可以给终端设置背景图片。
- **窗口在上次的位置打开**：多显示器时，窗口会回到上次关闭时所在的显示器和位置。
- **Files 右键菜单**：新增“打开”“在此新建会话”和“复制路径”。设置 › 终端 › 文件菜单可以关掉整个右键菜单，默认开启。
- **Windows**：会话改用随应用附带的 OpenConsole 运行，全屏程序里的滚轮和点击现在能用了；Windows 11 上背景模糊可以选 Mica 或 Mica Alt；PowerShell 里的 `cd /e` 会按 Git Bash 的写法进入 `E:\`。

## 性能

- 空闲的历史记录会压缩存放，翻看或搜索时再解开，长时间运行的会话更省内存。
- 纯文本输出处理更快；一行里颜色很多时，绘制也更快。

## 修复

- 输入法组合出换行时，应用不再崩溃。
- Wayland 下（例如 niri 配 fcitx5），Shift 和 Ctrl-Shift 组合键不再失灵。
- Windows 上回退字体的斜体不再显示成别的汉字。

## What's new

This release brings in upstream ELYTerminal 0.2.0.

- **Images in the terminal.** kitty's graphics protocol is supported, animations included, so programs that speak it show pictures inline. A session you switch away from gives its image memory back.
- **kitty's clipboard protocol (OSC 5522).** Programs can read and write text, images and file lists on the clipboard. A program asks before it reads, and you can allow it for the rest of the session.
- **Custom themes and a background image.** Settings › Appearance can start a theme of your own from Ely Dark and put a picture behind the terminal.
- **The window reopens where you left it**, on the same display when you have several.
- **Files menu.** A right press on a name now also offers Open, New session here and Copy path. Settings › Terminal › Files menu turns the whole menu off; it is on by default.
- **Windows.** Sessions run on the bundled OpenConsole, so the wheel and clicks reach full-screen programs. On Windows 11 the background blur can be Mica or Mica Alt. In PowerShell, `cd /e` goes to `E:\` as Git Bash would.

## Performance

- Idle scrollback is packed small and unpacked when you scroll or search, so long-running sessions use less memory.
- Plain text output is processed faster, and rows with many colors draw faster.

## Fixes

- An input method composing a newline no longer crashes the app.
- On Wayland (for example niri with fcitx5), Shift and Ctrl-Shift shortcuts work again.
- On Windows, italics in a fallback font no longer show the wrong CJK characters.
