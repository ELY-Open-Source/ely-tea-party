本版为即将上线的角色包市场做准备，`.elyskin` 升级到第 2 版。

## 新功能

- **角色包信息**：设置 › 角色 新增“角色包信息”，可以填写名称、作者和许可证。导出时会写进 `.elyskin` 文件，导入别人的包时自动显示。
- **更耐用的角色包格式**：以后的版本给角色包加了新字段或新动作，本版也能照常导入，不认识的动作会跳过，并告诉你跳过了哪些。遇到需要更新版本才能读的包时，会提示你更新。
- **更安全的导入**：动作名不合规、同一个动作重复出现、条目过多，或者作者名里藏着控制字符或伪装文字方向的字符，这样的包会被整个拒绝，已装好的皮肤不受影响。

## 兼容性

- 0.3.12 到 0.3.16 导出的角色包仍然可以导入。
- 本版导出的角色包需要 Ely Tea Party 0.3.17 或更新版本才能导入。
- 格式规范见 [docs/elyskin.md](https://github.com/ELY-Open-Source/ely-tea-party/blob/main/docs/elyskin.md)。

## What's new

This release gets `.elyskin` ready for the upcoming skin market by moving it to version 2.

- **Pack info.** Settings › Characters has a new Pack info section for the pack's name, author and license. Exporting writes them into the `.elyskin` file, and importing someone else's pack shows them.
- **A pack format that lasts.** Packs from later versions that add fields or actions still import here. Actions this version doesn't know are skipped, and it tells you which ones. A pack that needs a newer version asks you to update.
- **Safer imports.** A pack with an invalid action name, a repeated action, too many entries, or control or text-direction characters hidden in its credits is refused as a whole, and your installed skins stay as they were.

## Compatibility

- Packs exported by 0.3.12 to 0.3.16 still import.
- Packs exported by this release need Ely Tea Party 0.3.17 or later.
- The format is specified in [docs/elyskin.md](https://github.com/ELY-Open-Source/ely-tea-party/blob/main/docs/elyskin.md).
