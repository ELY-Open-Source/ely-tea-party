本版接入[皮肤市场](https://elyteaparty.com/skins/)，网页上看中的角色皮肤可以一键装进 App。

## 新功能

- **一键安装皮肤**：在皮肤市场点“在 Ely Tea Party 中安装”，Ely Tea Party 会自动打开 设置 › 角色，下载这个皮肤，核对文件和市场登记的一致之后显示“皮肤市场”卡片，点“安装”就能装到对应角色上。鲸鱼娘的皮肤只能装给鲸鱼娘，Agent 的皮肤可以装给任意 Agent。
- **App 已经开着也没关系**：点链接不会再开第二个窗口，皮肤会交给正在运行的那个。

## 兼容性

- 一键安装需要 0.3.18 或更新版本；旧版本仍然可以从市场下载 `.elyskin` 文件，再在 设置 › 角色 手动导入。
- Windows：首次启动本版时，会为当前用户登记 `elyteaparty://` 链接，不需要管理员权限。
- Linux：用 tarball 里的 `.desktop` 文件安装后，浏览器才能把链接交给 App。

## What's new

This release connects the app to the [skin market](https://elyteaparty.com/en/skins/), so a character skin you find on the web installs with one click.

- **One-click skins.** Press Install in Ely Tea Party on a market page and Ely Tea Party opens Settings › Characters, downloads the skin, checks the file against the market's listing, then shows a Skin market card. Press Install to put it on the character. Whale skins fit only the whale girl; agent skins fit any agent.
- **Works while the app is open.** A link no longer opens a second window: the running app takes the skin.

## Compatibility

- One-click install needs 0.3.18 or later. Older versions can still download the `.elyskin` file from the market and import it in Settings › Characters.
- Windows: the first start of this release registers `elyteaparty://` links for the current user, without admin rights.
- Linux: install the `.desktop` file from the tarball so the browser can hand links to the app.
