## 新功能

- **从 Cloudflare 检查和下载更新**：应用会先从 elyteaparty.com 的下载站读取最新版本，国内下载更快；读不到时自动改用 GitHub。macOS 下载更新后，会先核对下载站列出的 SHA-256，再像以前一样校验签名、公证和开发者团队。Windows 和 Linux 的更新按钮改为按界面语言打开官网下载页。

## 修复

- **识别独立安装的 dscode**：用 dscode 的 install.sh 安装的版本（`~/.local/bin/dscode`）现在也会显示鲸鱼娘；以前只有 Homebrew 安装的版本能被认出。

从 0.3.14 升级到本版时，更新仍从 GitHub 获取；之后的更新会从 Cloudflare 下载。

## What's new

- **Updates are checked and downloaded from Cloudflare.** The app first reads the newest version from elyteaparty.com's download store, which is faster to reach from China, and falls back to GitHub when it can't. On macOS the downloaded update must match the SHA-256 the store lists before the usual signature, notarization and developer-team checks. On Windows and Linux the update button opens the website's download page in the interface's language.

## Fixes

- **dscode's standalone install is recognized.** dscode installed with its install.sh (`~/.local/bin/dscode`) now shows the whale girl; before, only the Homebrew install did.

Upgrading from 0.3.14 still fetches this update from GitHub; later updates come from Cloudflare.
