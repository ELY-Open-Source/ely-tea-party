本版同步了上游 ELYTerminal 0.2.3，修好了 Activity 面板时灵时不灵的问题，右下角的额度也支持了 Antigravity。

## 新功能

- **配置档**：+ 旁边的菜单可以用你自己的命令行开会话，也列出这台机器上的 shell。
- **指定文件夹启动**：`ely-tea-party 文件夹` 会先打开这个文件夹，上次的会话排在后面恢复。Windows 上可以在 设置 › 终端 把“在 Ely Tea Party 中打开”加到资源管理器的右键菜单。
- **字体和背景**：可以单独设置界面字体、中日韩字体和字重；背景图可以调整大小、位置和平铺，背景不透明度可以调到 0%。
- **终端细节**：光标平滑移动，鼠标移到链接上显示下划线，文件树每秒自动刷新，并可以把文件拖进终端输入路径。
- **Antigravity 用量**：右下角显示 Gemini 的 5 小时和本周额度。
- **Codex banked reset 提醒**：3 天内过期显示黄色，1 天内过期显示红色。

## 修复

- **Activity**：并行工具和子 agent 不再出现重复的行，耗时也准确了；重启后记录还在；按 Esc 打断后不会一直显示“进行中”；闲置提醒不再算作提问；抽屉里的 agent 单独列在 Drawer 下。
- **文件树**：右键菜单和新建对话框不再中英混排。
- Windows 上的鼠标滚轮、粘贴和鼠标指针隐藏等来自上游的修复。

## 兼容性

- 开着“恢复会话”时，Activity 记录保存在配置目录的 `activity.json`，其中包含每条提示词的前 80 个字。
- Windows 默认打开“右键粘贴”，打开时右键不会弹出终端里的文件菜单，需要文件菜单的话请在 设置 › 终端 关掉它。
- 配置档开的会话在下次启动时会恢复文件夹，但用的是默认 shell。

## What's new

This release syncs with upstream ELYTerminal 0.2.3, makes the Activity tab dependable, and adds Antigravity to the usage foot.

- **Profiles.** The menu beside + opens sessions from your own command lines and the shells this machine holds.
- **Start in a folder.** `ely-tea-party FOLDER` opens that folder first, with your saved sessions after it. On Windows, Settings › Terminal can add Open in Ely Tea Party to Explorer's menu.
- **Fonts and background.** Separate interface and CJK fonts, a font weight, and a background picture you can size, place and tile. Background opacity goes down to 0%.
- **Terminal details.** The cursor glides, links underline on hover, Files refreshes every second, and a file dragged from Files types its path.
- **Antigravity usage.** The right column's foot shows the Gemini 5-hour and weekly limits.
- **Codex banked resets.** A note in yellow within three days of expiring, and in red within one.

## Fixes

- **Activity.** Parallel tools and subagents no longer repeat rows and keep their own times, steps survive a restart, Esc no longer leaves a turn running, idle reminders are no longer questions, and agents in a drawer list under Drawer.
- **Files.** The context menu and the new-file dialog no longer mix languages.
- Upstream's Windows fixes for the mouse wheel, paste and hiding the pointer.

## Compatibility

- While Restore sessions is on, Activity is saved in `activity.json` in the config folder, including the first 80 characters of each prompt.
- Right click pastes is on by default on Windows, and while it is on a right press does not open the terminal's file menu. Turn it off in Settings › Terminal to use that menu.
- A profile's session comes back in its folder at the next start, under the default shell.
