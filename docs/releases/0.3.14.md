## 修复

- **Agent Butler 记住 API Key**：在设置中应用密钥后，按服务商保存至系统凭据库，重启后自动读取。切换模型时留空会保留原密钥；需要删除时使用「移除已保存的密钥」。设置页会显示保存状态和读取、写入失败原因，密钥不会写入普通设置文件。
- **终端左侧 prompt 导航**：将 prompt 刻度移到终端内部左侧，独立留出空间，避免与右侧普通滚动条重叠。悬停预览 prompt 和回复，点击跳转到对应位置。

从旧版本升级后，需要重新输入并应用一次 API Key；旧版本只把密钥保留在进程内存中。Prompt 刻度依赖 agent hooks 上报及当前终端回滚记录中的对应文本，不会重建启动前的历史 prompt。

## Fixes

- **Remember Agent Butler API keys across restarts.** Keys are saved separately for each provider in the system credential store and loaded at launch. Applying an empty key preserves the saved key when changing models; use Remove saved key to delete it. Settings show credential status and read/write failures, while ordinary settings files remain free of API keys.
- **Prompt navigation inside the terminal's left edge.** Markers now have their own gutter beside the text, separate from the ordinary history scrollbar on the right. Hover to preview a prompt and reply, or click to jump to it.

After upgrading, enter and apply your API key once: previous versions kept keys only in process memory. Prompt markers require installed agent hooks and matching text in the current terminal scrollback; earlier prompts are not reconstructed at launch.
