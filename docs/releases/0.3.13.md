## 新功能

- **鲸鱼娘任务卡片**：点击鲸鱼娘即可查看各会话状态、近期任务和待处理事项，一键跳转对应会话。默认在本地生成，不消耗模型 token；需要时再点 AI 解读。
- **偶尔聊两句**：在「设置 → Agent Butler」开启后，停留在正在工作的会话、5–10 分钟没有操作时，鲸鱼娘会偶尔结合当前项目提一句建议。恢复输入、切换会话或离开窗口会停止。使用短上下文，每次输出上限 160 token，至少间隔 20 分钟，每小时最多 3 次尝试。
- **她记得的事**：可选本地记忆，分别保存表达偏好和项目记录。支持查看来源、查找、修正、撤销、忘掉和清空，也可以直接回应鲸鱼娘的建议。
- **克制地使用记忆**：普通闲聊默认不召回项目历史；只有同项目、同一未解决任务明确匹配时，才最多带入 2 条记录。相似建议会在本地去重，AI 整理出的记录会标明尚未确认。
- **独立控制 AI 整理**：本地记忆、主动发言、AI 整理都有独立开关，默认关闭。AI 整理每小时最多 2 次，至少间隔 30 分钟，跨重启保留用量限制。
- **更清晰的会话列表**：左侧 session 之间增加细分隔线和留白，保留选中项底色。

记忆保存在本机 SQLite 中，带有事件保留期限、容量限制和清理机制。API Key 不写入记忆库。AI 功能使用你在 Agent Butler 中配置的模型与凭据；本地任务卡片和手动记忆管理不需要模型调用。

## What's new

Click the whale for local task cards, session status and direct navigation without spending AI tokens. Request a bounded AI explanation only when needed.

Opt into occasional project suggestions after 5–10 quiet minutes watching a working agent. Suggestions use short context, a 160-token output limit, a 20-minute cooldown and at most three attempts per hour per app run.

Local memory separates explicit expression preferences from project records, with sources, search, corrections, undo and deletion. Historical recall is restricted to an exact unresolved-task match; ordinary remarks do not search project history. AI organization has a separate, default-off switch and a persistent two-attempts-per-hour budget. Storage retention and capacity guards keep the database bounded.

Sidebar sessions now use light separators and spacing. Linux packaging's runtime validation also passes ShellCheck.
