A FEW THINGS TO KNOW

入座之前。

这是一个新的 AI 模型吗？+

不是。Ely Tea Party 是一个原生终端，你仍然使用自己的 Claude Code、Codex、Gemini 等工具及其账号。Ely 把会话状态变成动画角色，并提供会话管理、Git、文件和活动信息。

需要填写 API Key 才能使用吗？+

终端、角色和本地任务卡不需要 Ely 的 API Key。你的 coding agent 按自身方式登录。鲸鱼娘的 AI 解释和建议是可选功能，开启后才需要配置对应的模型服务。

可以换成自己的角色吗？+

可以。在「设置 → 角色」导入 PNG、APNG、GIF、WebP 或完整的 .elyskin 形象包，也可以给不同动作配置不同动画。你能导出自己的形象包分享给朋友；网站形象市场尚未开放。

和 ELYTerminal 是什么关系？+

Ely Tea Party 是获得作者许可的 ELYTerminal 分支。底层终端和原有设计来自 Zachary Zhang 与 ELYTerminal；这个分支加入了 coding agent 角色、鲸鱼娘和相关工作流。认识原项目 ↗
