# Compact agent icons

Claude, OpenAI, DeepSeek and Gemini SVGs come from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under CC0-1.0. Local source: ppt-master/templates/icons/simple-icons. They identify the corresponding agents; marks remain their owners’ trademarks.

Kimi comes from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/a94750e3f5f8fc33757b839d85030e742284e43a/packages/static-svg/icons), via cmux’s attributed copy. Its MIT license is included as LOBE-LICENSE.txt.

Grok, Pi and OpenCode use a bolt, a pi lettermark and a code glyph from the application’s existing primitives. All icons use the theme’s foreground color.
